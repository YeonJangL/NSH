관게형 데이터베이스 용어

-릴레이션이라는 표
- 속성 = 열 = 필드      속성(열)
- 튜플 = 행 = 레코드	튜플(행)
- 차수 : 속성의 개수
- 기수 : 튜플의 개수
- 도메인 : 하나의 속성에서 취할수 있는 원자값들의 집합 ex. 성별 : 남/여
- 릴레이션 인스턴스 : 릴레이션에 실제로  저장된 데이터 집합/상태


*릴레이션 특징
-튜플과 속성은 유일하며 순서는 무의미함
- 속성으 NULL값을 가질수 있으나, 기본키에 해당되는 속성은 NULL값 불가

키
- 후보키 : 모든 튜플에 대해 유일성/최소성만족 
	유일성 : 하나의 키 값으로 하나의 튜플 유일하게 식별
	최소성 : 모든 레코드 식별하는데 최소한의 속성으로만 구성
- 기본키 : 후보키중 선택, 중복된 값과, NULL값  불가
- 대체키 : 후보키가 둘 이상일때 기본키 제외한 후보키
- 슈퍼키 : 유일성 o , 최소성 x
- 외래키 : 다른 릴레이션의 기본키를 참조하는 속성 들의 집합
	참조되는 릴레이션 기본키와 대응되어 릴레이션 간 참조


무결성
- 개체 무결성 : 기본키를 구성하는 어떤 속성도 NULL/중복값 가질수없음
- 도메인 / 속성 무결성 : 릴레이션내 튜플들이 각 속성의 도메인에 지정된 값만 가짐
- 참조 무결성 : 외래키는 NULL 또는 참조 릴레이션의 기본키 값과 동일
			릴레이션은 참조할 수 없는 외래키 값을 가질 수 없음
- 사용자 정의 무결성 : 속성 값들이 사용자 정의 제약 조건에 만족
- 데이터 무결성 강화 : 데이터 특성에 맞는 무결성 정의 강화
				제약조건, 어플리케이션, 데이터베이스 트리거

접근 통제 기술AC

				GRANT/REVOKE

- 역할 기반 접근 통제(RBAC) : 사용자의 역할에 따라 접근권한부여(중앙관리자가 지정)
					다중 프로그래밍 최적

정구화 과정
도부이결다조

1	: 모든 도메인이 원자값으로 됨
2	: 완전 함수적 종속 만족, 부분적 함수 종속을 제거
3	: 이행적 함수 종속 관계를 만족하지 않아야함 (x->y,y->z 이면 x->z)
BCNF	: 릴레이션 R에서 모든 결정자가 후보키인 정규형
4	: 다치종속이 성립하는 경우 r의 모든 속성이 a에 함수적 종속 관계를 만족
5	: 모든 조인 종속이 R의 후보키를 통해서만성립

* 반정규화 : 정규화 과정 진행 후, 시스템 성능 향상 및 운영 편의성을 위해 의도적 데이터 중복/통합/분리를 허용(무결성저해)
		정규화 원칙을 위반

* 함수적 종속
- 완전 함수적 종속 : 종속자가 기본키에만 종속
- 부분 함수적 종속 : 기본키가 여러 속성으로 구성 되어있을 떄 기본키를 구성하는 속성중 일부만 종속
- 이행적 함수 종속 : X->Y Y->Z 이면 X-> Z

트랜잭션
하나의 논리적 기능을 수행하기 위한 작업 단위
-원자성 : 트랜잭션 연산이 정상적으로 수행 혹은 어떠한 연산도 수행되지 않아야함 Commit/rollback)
-일관성 : 시스템의 고정 요소는 트랜잭션 수행 전/후로 동일
-독립성 : 개별 트랜잭션은 다른 트랜잭션의 간섭 및 영향 받지 않아야 함
-영속성 : 완료된 트랜잭션 결과는 영구적으로 기록되어야 함

COMMIT : 트랜잭션 정상 종료 후 변경된 내용 반영
ROLLBACK : 비정상 종료후 이전상태 복원
REDO : 이전값을 이후값으로 변경
UNDO : 이후 값을 이전 값으로 변겨 ctrl_Z느낌?

알고리즘
- 선형검색 : 하나씩 순서대로 찾는것
- 이진 검색 : 검색 수행전에 데이터 집합이 정렬

- O(1) 	해시함수 	 자료크기무관일정한속도
- O(log₂N) 이진탐색 	로그형복잡도
- O(n)	순차탐색	선형복잡도: 입력자료를하나씩처리(정비례)
- O(N log₂N)	힙/ 합병(병합)정렬	선형로그형복잡도
- O(N²) 	선택/ 버블/ 삽입 퀵정렬	대부분의경우힙/합병보다복잡도가큼 N² > N log₂N (N > 2) 


정렬 알고리즘
- 삽입 : 이미 정렬된 파일에 순서에 맞게 삽입정렬
- 선택 : n개의 레코드중 최소값을 찾아 처번째에 배치 나머지 n-1개 레코드 중 최솟값 찾아 두번째, 반복
- 버블 : 인전합 두개의 레코드 비교 위치 바꿈
- 퀵 : 자료 이동 최소화 후 하나의 파일을 나눠 정력
- 2-WAY 합병 : 이미 정렬된 2개의 파일을 한개의 파일로 합병
- 쉘 : 입력 파일을 매개 변수 값으로 서브파일 구성 후 서브파일을 삽입 정렬방식으로 순서 배열하는 과정 반복
- 힙 : 완전 이진 트리를 이용한 정렬
