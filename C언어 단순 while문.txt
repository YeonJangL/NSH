★ while 구문
while 구문은 조건을 만족하는 동안 계속 반복해라는 뜻 프로그램에게 어떤 조건이 참인 동안은 특정한 일을 계속 하라고 지시

int i = 0; // i를 0으로 시작
while ( i < 5) { // i 가 5보다 작은 동안 아래 명령을 반복
printf("%d\n" , i ) // i의 값을 화면에 보여줌
i ++ // i  를 1씩 증가시킴 증감이라고 함
}

이 프로그램은 i을 0에서 시작해서 1씩 증가시키면서 i의 값이 5보다 작을 때까지 i의 값을 화면에 출력함
i가 5가되면 조건 i < 5가 거짓이 됨 그래서 while문은 끝
화면에는 0부터 4까지 숫자가 차례로 보여짐

반복문에서 0을 아무리 곱해도 0
