c언어 - 정적 변수

★정적변수
1. 메모리에 한 번만 할당돼요
- 정적변수는 프로그램이 실행될 때 메모리에 할당되고, 프로그램이 종료될 때까지 그 값을 유지해요
- 그래서 함수가 여러 번 호출되더라도 새로 초기화되지 않아요
2. 초기화는 한번만 이루어짐
- 정벅 변수를 선언할 때 초기값을 주면, 프로그램 실행 시 한번만 초기화됨
- 이후에는 이전에 저장된 값을 그래도 사용함

정적변수(static)의 특성과 지역변수와의 차이, 그리고 변수의 스코프를 이해하고 있는지 확인하는 문제. 특히, 함수 내부의 정적 변수가 호출될 때 호출될 때 어떻게 값이 유지되는지를 알아보는게 목적


C언어 구조체
★구조체
구조체란, 여러 가지 다른 종류의 변수를 하나로 묶어 새로운 형태의 데이터 뭉치를 만드는 것
마치 일상에서 서로 다른 물건들을 하나의 상자에 담아 정리하는 것과 같음
예를 들어, 친구한명을 생각할때. 이친구에 이름 나이 전화번호와 같은 정보가있음
c언어의 구조체를 사용하면 이런 정보들을 한데 모아 '친구'라는 하나의 구조체로 만들수 있음
struct Friend{
	char name[50];
	int age;
	char phone[15];
};

구조체 생성
struct Friend myFriend;

직접 접근
myFriend.name, myFriend.age, myFriend.phone처럼 점(.)을 사용해 해당 친구의 정보에 바로 접근할 수 있음

구조체 배열로 생성하기
struct Friend myFridends[5];

배열접근
myFridend[0].name 이렇게 배열의 인덱스를 사용하여 접근. 여기서 0은 배열의 첫 번째 친구를 의미

구조체 포인터로 생성하기
struct Friend *ptrFriend;
ptrFriend = &myFriend;

포인터 접근
ptrFriend->name, ptrFriend -> age, ptrFriend -> phone처럼 화살표(->)를 사용해 포인터가 가리키는 구조체의 정보에 접근하면 돼요

★ 구조체의 내부 변수에 접근하는 방법은 일반 변수로 선언했다면 점, 구조체 포인터로 선언했다면 -> 로 접근이 가능


★ 구조체와 포인터를 활용한 연결 리스트의 조작에 대해서 묻는 문제
구조체 포인터를 사용하는 방법과 이를 이용한 값 변경 로직을 이해하고 있는지 확인
