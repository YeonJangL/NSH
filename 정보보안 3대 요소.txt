서비스 공격 유형
- 서비스 거부 공격 DOS : 대량의 데이터를 한곳의 집중
- 분산 서비스 거부 공격 DDOS : 여러대의 장비에서 한곳의 서버에 분산서비스 공겨
- Ping of death : 허용 범위 이상의 ICMP 패킷을 전송
- ping Flooding : ICMP 메세지에 의한 응답과다로 시스템 에러 유발
- SYN Flooding : ACK 패킷 신호를 고의로 누락한 채 SYN 패킷 신호만 전송하여 각 서버의 가용 사용자수를 선점후 연결상태 유지
- UDP Flooding : 다량의 UDP 패킷을 전송하여 네트워크 자원을 고갈
- Smurfing(스머핑) : IP/ICMP 특성을 악용하여 엄청난 양의 데이터를 한 사이트에 집중적으로 보냄
- TearDrop : Fragment number 값을 변형
- LAND Attack : 송/수신 IP 주소를 모두 타켓 IP주소로 하여 자신에게 무한히 응답하게 함
- Phishing : 악의적 사용자가 사칭하여 정보 탈취
- evil twin attack : 실제 WIFI신호를 송출 연결한사람정보 탈취
- Switching Jamming : 위조된 매체 접근제어(mac) 주소를 지속 보내 스위치 MAC주소를 혼란시켜 더미 허브 작동


정보보안 솔루션
- VPN : 공중네트워크 암호화 기술 사용하여 사용자가 마치 자신의 전용 회선을 사용하는 것처럼 하게 함
- NAC : 네트워크에 접속하는 내부 PC의 MAC 주소를 IP 관리 시스템에 등록한 후 일관된 보안 관리 기능을 제공
- SIEM : 보안 경고의 실시간 분석 제공 로그 및 이벤트 통합관리 / 빅데이터 기반 보안 솔루션

침입 탐지 시스템
- 시스템의 비정상 사용/오용/남용 등을 실시간 탐지
- 오용 탐지 : 사전에 정립되어 입력해둔 공격 패턴 감지 시 통보
- 이상 탐지 : 평균적인 상태 기준에서 비정상적 행위 또는 자원의 사용 감지 시 통보
[종류] 
- HIDS : 시스템 내부 감시/분석, 내부 변화를 실시간으로 감시 외부 침입자 작업 기록 및 추적
	-> OSSEC, md5deep, AIDE, Samhain
- NIDS : 외부 침입 감시/ 분석, 네트워크 트래픽 감시
	-> Snort, Zeek
- IDS 설치 가능 위치  :패킷 라우터로 들어오기 전 / 라우터 뒤 / 방화벽 뒤 / DMZ
		DMZ : 외부 인터넷에 서비스 제공하는 서버가 위치하는 네트워크
